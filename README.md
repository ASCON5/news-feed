# news-feed

Бот, который сам собирает новости и «возможности» (CTF, олимпиады, хакатоны, гранты, стипендии)
и публикует их в Telegram-канал. Работает бесплатно на GitHub Actions, без своего сервера.

## Что умеет

- Собирает записи из RSS, публичных Telegram-каналов, CTFtime, Codeforces и Devpost.
- Убирает дубли (одинаковые ссылки и похожие заголовки), фильтрует рекламу.
- Публикует посты с фото, если оно нашлось; если Telegram не принял картинку, шлёт пост без неё.
- Ставит теги по теме (`#ИИ`, `#безопасность`, `#разработка`, `#железо`, `#игры`, `#наука`).
- Соревнования и гранты оформляет карточкой: что это, когда, до какого числа регистрация,
  формат, кто может участвовать, что нужно, что делать.
- Лимиты: новости и возможности считаются отдельно (по умолчанию до 5 за запуск, 20 и 12 за сутки).

## Как это устроено

```
GitHub Actions (по расписанию) -> newsbot.py -> Telegram-канал
                                      |
                                data/state.json (память: что уже отправлено)
```

Файлы: `newsbot.py` (вся логика), `sources.yml` (источники и настройки),
`.github/workflows/news.yml` (расписание), `data/state.json` (память бота, не править руками),
`tests/` (автотесты).

## Запуск с нуля

1. Создай бота у `@BotFather`, скопируй токен. Создай канал и добавь бота админом с правом публикации.
2. В репозитории: Settings -> Secrets and variables -> Actions, добавь секреты
   `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (`@имя_канала` для публичного).
3. Actions -> news -> Run workflow с галочкой `Пробный режим`: бот ничего не публикует, а печатает в лог,
   что отправил бы. Так видно, какие источники работают.
4. Запусти без галочки. Первый боевой запуск только запоминает текущие записи и ничего не публикует.
5. Чтобы включить автозапуск, в `news.yml` раскомментируй блок `schedule`.

Остановить бота: Actions -> news -> `...` -> Disable workflow.

## Как добавить источник

В `sources.yml`, раздел `sources`, одна строка:

```yaml
- {name: Хабр, type: rss, url: "https://habr.com/ru/rss/articles/?fl=ru", tag: разработка}
- {name: CodeCamp, type: telegram, channel: campcode, preview: false, tag: разработка}
```

Типы: `rss`, `telegram` (только публичные каналы с веб-превью), `ctftime`, `codeforces`, `devpost`.
Для соревнований и грантов добавь `kind: opportunity`. Отключить источник: `enabled: false`.
Фото у источника отключается так: `images: false`.

## Ограничения

- Расписание GitHub Actions неточное: запуск может опаздывать на 10-20 минут.
- В публичном репозитории GitHub может отключить расписание при долгой неактивности.
  Бот раз в сутки обновляет `state.json`, чтобы этого избежать, но гарантии нет.
- Тексты грантов остаются на языке оригинала, перевода нет.
- «Кто может участвовать» и «что нужно» для CTF и хакатонов заполняются по общим правилам,
  это подсказка, а не проверка условий. Всегда читай официальные правила по ссылке в посте.
- Для CTFtime действуют условия их API: используй бота для личного канала со ссылкой на оригинал,
  не как зеркало сайта.
- Репозиторий публичный: токены и секреты хранятся только в GitHub Secrets, не в коде.
